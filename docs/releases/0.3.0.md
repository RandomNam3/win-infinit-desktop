Neuer Name: Aus „WIN Infinit Desktop“ wird **WIN Infinite Desktop**, passend zu „infinite“, dem englischen Wort für unendlich. Das Repository heißt jetzt [RandomNam3/win-infinite-desktop](https://github.com/RandomNam3/win-infinite-desktop), die Windows-Version heißt wie ihr Vorbild [KDE Infinite Desktop](https://github.com/RandomNam3/kde-infinite-desktop).

## Geändert

- **Name überall:** Programme (`win-infinite-desktop.exe`), Startmenü, Autostart, Eintrag unter *Einstellungen → Apps*, Infobereich und die Ordner `%APPDATA%\WIN Infinite Desktop` und `%LOCALAPPDATA%\WIN Infinite Desktop`.
- **Bestehende Installationen werden übernommen:** Das Update aus der Einstellungs-App und der Installationsbefehl funktionieren wie gewohnt.
  - Der alte Dienst wird sauber beendet, alle Fenster kommen auf den Bildschirm zurück.
  - Die alte Installation samt Startmenü-Ordner, Autostart und Apps-Eintrag verschwindet.
  - Einstellungen, Tastenkürzel, Notizen, Arbeitsflächen, Lesezeichen, Gruppen, Bereiche und gemerkte Fensterplätze ziehen in die neuen Ordner um.
- **Ohne Installer:** Wer die Programme direkt aus dem ZIP startet, bekommt die alten Daten beim ersten Start ebenfalls übernommen.

## Installation

Direkt aus der Einstellungs-App aktualisieren oder in PowerShell:

```powershell
irm https://raw.githubusercontent.com/RandomNam3/win-infinite-desktop/main/install.ps1 | iex
```

Voraussetzungen: Windows 11 24H2 oder neuer, x64 (Windows on ARM führt das x64-Paket aus).
